# Notice: Rocketbox pedestrian models (peds24/rb27)

These pedestrian bodies and textures are converted from the Microsoft Rocketbox Avatar Library
(https://github.com/microsoft/Microsoft-Rocketbox): Gonzalez-Franco et al., "The Rocketbox library and the utility of
freely available rigged avatars", Frontiers in Virtual Reality (2020), doi:10.3389/frvir.2020.561558.

Changes: FBX -> glTF (FBX2glTF), the Biped skeleton re-bound to the CARLA GEN2 walker skeleton so the peds24 clips drive
it, level-of-detail meshes, textures resized and packed into KTX2 texture arrays, bags and phones from the peds24 prop
set fitted to each body. The walk, run and idle clips are the peds24 clips (CARLA and 100STYLE, CC BY 4.0).
