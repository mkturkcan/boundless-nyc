Fonts for the AR33 storefront and landmark signs (client/src/city/fk/signKit.js, signPaint.js).

Every TTF is a raw file from github.com/google/fonts (ofl/<family>/ or apache/<family>/), fetched 2026-09-30 by
client/tools/ar33/signs/fetch_fonts.mjs. Variable files are saved under safe names: 'Inter[opsz,wght].ttf' is
Inter-opsz-wght.ttf here (the file itself is unchanged). Each family's licence is LICENSE-<dir>.txt beside it (SIL Open
Font License 1.1, or Apache License 2.0 for Roboto Slab and Yellowtail), copied from the same directory of the repo.

o/*.json are three.js typeface outlines converted from these files by tools/ar33/signs/mk_outlines.mjs (fontkit):
a format conversion, so a Modified Version under the OFL. They stay under the font's own licence (named in each file's
original_font_information), and a family whose licence reserves its name is presented as 'AR33 outline <n>'.
